# Ice & Easy
This is a fun game made in Godot for Snowglobe- a girls-only hackathon hosted in San Francisco for teenagers to be creative and make their own projects!

​You play the game (which we titled ice & easy) as the main character Chip Matthew Cone, an ice cream character who is determined to save his friends after disappearing in an icy freezer. So far, we've hand drawn the background, effects, ice sprites, and characters. You are able to see your health bar displayed- which can lower after hitting harmful spikes and increase after consuming a health assist heart.

**live demo:** https://dipa-cotton.itch.io/ice-easy

## how do you use it?
you use this project by playing it in your browser! there is an itch.io link above, and when opened, you can access the game in your browser and play it!

## how we built it

We built this game in Godot- using gdscript as our language and using the Godot Game Engine to support everything we created!

## run it yourself
1. clone the repo
2. download the files
3. open godot and upload all files
4. play!

## what was hard, and how we fixed it
it was incredibly hard to debug, but we fixed it by asking for help, working together, and using tutorials online to solve issues.

## what's next
in the future, we may add more levels and make our game more complex for others to play!
after finishing the game, we built a little snowflake out of LEDs that can be powered on, it congratulates you on defeating the enemies!
